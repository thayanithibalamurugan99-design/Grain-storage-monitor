# Smart Grain Storage Monitor & Automatic Protection System

An IoT and AI-driven dashboard for real-time monitoring of grain storage environments. This system tracks environmental conditions, calculates spoilage risks, and triggers automated alerts to protect stored crops.

## 🚀 Live Demo
- **Live Web App:** [https://grain-storage-monito-85d8.bolt.host](https://grain-storage-monito-85d8.bolt.host)

## ✨ Key Features
- **Real-Time Sensor Monitoring:** Tracks temperature, humidity, and gas/moisture levels.
- **Spoilage Risk Calculator:** Analyzes environmental thresholds to predict grain degradation.
- **Alert System:** Visual indicators and notifications for high-risk conditions.
- **Historical Data Analytics:** Interactive charts for environmental trend analysis.

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS
- **Charts & UI:** Lucide Icons, Recharts
- **Build Tool:** Vite
